# 设计范围

业务要求：期刊指南、范文与证据文献分离；章节论点追溯。

已实现：摘要原句匹配、十字理由约束、证据记录检查。算术和字段约束交给Python，阅读和组织材料通过skill指令约束。初始实现使用AI辅助开发，实际贡献按修改与验证记录说明。

## 文献证据分层

范文用于观察论证方法；来源文献用于支持论点；期刊指南用于核对硬性要求，三者分别记录。每篇文献保留摘要快照、原句、位置与参考理由。

工具只允许空白差异的本地引文匹配，理由去除首尾空白后按Unicode字符计1—10字。它不识别完整句界、不联网证明论文存在，也不验证论点蕴含关系。example.invalid来源能通过URL格式检查，不能当作真实文献。
