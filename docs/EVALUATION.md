# 独立项目验证

在项目根目录运行python3 scripts/reproduce.py，执行4项单元测试及2个合成CLI场景。该命令不调用模型或网络，重新运行会替换docs/results/记录。

receipt.json记录版本、时间、命令和退出码，unit-tests.txt包含逐项测试结果。CLI复现检查预期退出码并保存实际JSON；单元测试检查关键状态和数值。这些样本不是随机业务数据，不计算模型准确率。

核心工具来自已有原型，拆分时隔离相关测试并重新执行。这里的4项测试是原型10项中的相关子集，不能与原型数量相加声称测试翻倍。

文献来源真实性、完整句界和语义支持仍需核验；未提供目标期刊或真实范文。
