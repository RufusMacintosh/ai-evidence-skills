# 设计范围

业务要求：监管分母与预测负荷分离；总量覆盖与分时敞口分离。

已实现：预测覆盖率、分时缺口和超额、传入规则记录检查。算术和字段约束交给Python，阅读和组织材料通过skill指令约束。初始实现使用AI辅助开发，实际贡献按修改与验证记录说明。

## 两个口径分别计算

预测覆盖率=总合同覆盖电量/总预测负荷；监管比例使用单独传入的分子和分母。每时段缺口=max(负荷−合同,0)，超额=max(合同−负荷,0)，分别累计，不先相抵。分母为零时预测覆盖率返回null。

合成示例总覆盖100%，仍有缺口/超额各50MWh。verified字段是人工标记，matches_supplied_threshold只代表对传入记录的范围、日期与算术检查。工具仅检查slot标签重复，实际区间重叠与完整性仍需核对；负净头寸和极端数值溢出暂未全面处理。
